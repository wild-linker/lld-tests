This repository vendors two linker test suites:

- `llvm-tests/` contains [LLVM LLD tests](https://github.com/llvm/llvm-project/). See `llvm-tests/REVISION.txt` and [the LLVM license](LLVM_LICENSE.TXT).
- `mold-tests/` contains [mold tests](https://github.com/rui314/mold). See `mold-tests/REVISION.txt` and [the MIT license](MOLD_LICENSE.txt).

Run `./update-tests.sh` to refresh both suites.
